# TaskWeave

[中文](#中文) · [English](#english)

## 中文

TaskWeave 是一款本地任务管理软件。在看板里安排和完成任务，在甘特图里回顾哪天做了什么。

### 下载

适用于 **Windows 64 位**。打开 [Releases](https://github.com/oatmeal121/TaskWeave/releases)，下载 **Assets** 中的 `TaskWeave_*_x64-setup.exe`，双击安装。

### 使用

1. 在看板点击「新建」，填写任务名称。可以标记是否重要、是否紧急：卡片的蓝色深浅表示重要程度，红色深浅表示紧急程度。
2. 任务默认出现在「待办」。开始做时，用卡片左侧的拖动手柄移到「进行中」；完成后再拖到「完成」。
3. 当天做过，点任务上的勾选按钮（「今天做了」）记录一下，以后就能在甘特图中回顾工作情况。

任务多了，可以按项目、子项目整理。经常重复的事可以设成重复任务；会议或其他需要记住的时间，可以设置提醒。

更多操作见软件内的「使用指南」。关闭窗口后，软件会留在系统托盘；单击托盘图标恢复，右键菜单可退出。

### 数据与备份

数据保存在本机。通过「设置 → 数据迁移与备份」导出 JSON 文件，在另一台电脑上导入即可迁移。导入会补充记录，保留已有相同记录的当前内容。

更新或换电脑前建议导出一份备份。卸载时若要保留记录，不要勾选 **Delete the application data（删除应用数据）**。

## English

TaskWeave is a local task manager. Plan and complete tasks on a Kanban board, then use the Gantt view to look back at what you worked on each day.

### Download

For **64-bit Windows**. Open [Releases](https://github.com/oatmeal121/TaskWeave/releases), download `TaskWeave_*_x64-setup.exe` under **Assets**, and run the installer.

### Getting started

1. Click **New** on the board and enter a task name. You can mark it as important or urgent: darker blue means important, and darker red means urgent.
2. New tasks appear in **Todo** by default. Use the handle on the left of a card to drag it to **Doing** when you start, then to **Done** when you finish.
3. Click the task’s checkmark button (**Today**) to record that you worked on it that day. You can review these records in the Gantt view later.

Use projects and subprojects to organize your tasks as the list grows. Set up recurring tasks for regular work, or reminders for meetings and other events.

The in-app **User guide** explains more. Closing the window leaves TaskWeave in the system tray. Click its tray icon once to reopen it, or right-click to exit.

### Data and backups

Your data stays on your computer. Use **Settings → Data transfer and backup** to export a JSON file, then import it on another computer to move your records. Import adds missing records and preserves existing ones.

Export a backup before updating or changing computers. To keep your records when uninstalling, leave **Delete the application data** unchecked.
